# 笔锋 · PySide6 实时战略

平面地图上的小型即时战略原型。核心操作是**用画笔下达行军路线**：选中兵团后，
在地图上按住右键画一条线，兵团就沿着这条笔迹推进——遇到湖泊会自动绕行。
战斗刻意偏「僵持」：血厚、伤害低，据守方极难被正面啃动，逼你靠集火与包抄破局。

## 运行

```bash
pip install PySide6
python main.py
```

启动后先进入**开始界面**：选择难度（简单／困难）、可填地图种子（留空随机），点「开始战斗」；
也可点「**地图编辑器**」进入编辑模式，自己布置一张战场再试玩（见下文）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点击兵团 | 选中（按住 Shift / Ctrl 加选） |
| 左键拖拽空地 | 框选 |
| **右键点可见敌军** | **指定攻击**（远程环站位/近战贴脸分槽；光标十字、闪红圈；多选显示「N 团集火」） |
| 右键点地 | 按当前指令模式向该点下令（默认移动） |
| **右键拖拽** | **画出行军路线，松手后照笔迹执行** |
| **Shift+右键** | **指令排队**（不打断当前；可连续多点移动 / 先路线再点敌） |
| M / A / P | 切换指令模式：移动 / 攻击移动 / 巡逻（点敌始终＝锁定攻击） |
| Q | 编队锁定开关（同步限速、保持队形） |
| **H / R** | **停止 / 战术撤退**（向出生侧短撤，途中不主动接敌） |
| **Ctrl+1..9** | **把当前选中存入编组** |
| **1..9** | **召回编组**（短时连按同一键＝居中） |
| 中键拖拽 / 方向键 | 平移视角 |
| 滚轮 | 缩放（以光标为中心） |
| 空格 | 暂停 |
| T / G / F | 势力图层 / 网格 / 战争迷雾 开关 |
| Ctrl+A / H / R / J / F5 / Tab / Esc | 全选 / 停止 / 撤退 / 托管 / 新战场 / 居中 / 返回主菜单 |
| 点击右下小地图 | 快速跳转视角（淡红点＝曾见敌军的敌情记忆） |
| **战况记录** | 侧栏按钮：暂停并打开军力折线 + 时间线；战斗结束结算同图 |

## 指令模式

工具栏按钮或快捷键切换右键下达的指令类型（三种模式均支持画笔路线与单击）：

| 模式 | 快捷键 | 行为 |
| --- | --- | --- |
| **移动** | M | 点地/拖拽＝沿路线行进，接敌即停（默认） |
| **攻击移动** | A | 点地/拖拽＝遇敌交战，**灭敌后续程** |
| **巡逻** | P | 点地/拖拽＝路线两端往返，遇敌交战后继续巡逻 |

三种模式下 **右键点可见敌军** 都是指定攻击（锁定该团），与点地语义分开，避免「以为点了敌其实下了移动」。

**编队（Q）**：开启后，选中兵团以编队内最慢兵种的速度同步推进，保持间距不脱节、
不抢跑；路线走完后自动解除。可叠加在任意指令模式上。

**控制编组**：`Ctrl+1..9` 记住当前选中，`1..9` 一键召回；连按同一数字会把视角拉到该组。

画笔预览时，笔迹穿过的**湖泊**会标红、需要绕行的段画橙色虚线，让你在下笔时
就看到哪里会被挡、会自动绕行。

## 兵种（形状区分兵种，颜色区分敌我）

| 兵种 | 外形 | HP | 速度 | 攻击 | 射程 | 特点 / 克制 |
| --- | --- | --- | --- | --- | --- | --- |
| 步兵团 | ● 圆 | 520 | 42 | 12 | 48 | 皮厚耐战，**克骑兵**（拒马 +25%） |
| 骑兵团 | ▲ 三角 | 400 | 78 | 15 | 34 | 机动最快，**冲垮弓（+35%）/炮（+45%）**，冲锋头几刀最重 |
| 弓兵团 | ◆ 菱形 | 320 | 40 | 13 | 122 | 中程输出，**风筝步兵**（+20%），需前排掩护 |
| 炮兵团 | ⬢ 六边形 | 300 | 27 | 26 | 178 | 射程最远、单发最重，**轰步阵**（+15%），破据守利器 |

蓝＝我军，红＝敌军。选中有金色描边，静止扎营会浮现青色「据守」光环。

## 战斗与「僵持」

数值偏消耗：1v1 步兵在平原要约 **40 秒**才能分出胜负（早期原型仅 ~10 秒）。
两项机制把前线拖成拉锯：

- **地形防御**：森林 +30%、丘陵 +20%、山地 +55%，河流上防御骤降（半渡而击）。
- **据守**：静止约 4 秒逐步获得最高 **+35%** 防御。守军扎在山地满据守，正面强攻要
  **90 秒以上**才能拔掉。因此死磕正面极不划算，得靠**集火**或**骑兵包抄**撕开缺口。

## 士气与溃逃

每个兵团有一条**士气**（悬停或选中可见；动摇后兵牌上方会出现细条）。掉血、被侧击/
背击、被骑兵冲锋、目睹附近友军覆灭都会动摇军心；士气跌破 **25%** 即**溃逃**——
灰色兵牌打出白旗，不受指挥、不还手，向己方后方逃窜（追杀溃兵是收割战果的好时机）。
脱离战斗后士气缓慢回稳，回到 **55%** 会**重整归队**；逃到地图边缘则**溃散离场**，
计入损失。一方只剩溃兵时即判负——歼灭战往往在「击溃」而非「杀绝」时就已定局。

## 老练度

兵团靠战功（输出 + 击破）晋升：**老练 → 精锐 → 禁卫**（兵牌左上金色军功纹，1~3 道）。
每级输出 **+8%**、士气损失 **-14%**——百战老兵打得更狠、更不容易崩。保住高战功
部队、拿残血敌团喂经验，是滚雪球的关键。

## 战争迷雾

默认开启（**F** 切换）：我军视野圆之外罩上暗雾，看不见的敌军完全隐形（主图、小地图、
悬停一律不显示）。视野受地形加成（丘陵/山地看得远），**藏进森林的敌人要贴到很近
才会现身**——侦察与反侦察都围绕地形展开。

## 势力（占领区）图层

半透明图层把整张战场**一分为二**：每格按双方影响力谁强归给谁（兵团按距离衰减向四周
投射影响力），我方蓝、敌方红，两片领土直接相接，接触处描出一条**清晰的前线**——
没有渐变、也没有无主的中间地带（按 **T** 开关）。侧栏「**军力对比**」条按双方存活兵力
（HP × 老练加成，溃兵折三成）实时对比，金色交锋线随战损缓缓推移——它衡量的是
**军队实力**而非控制面积，是判断这一仗打得亏不亏、该不该继续投入的直观依据。

## 难度

| 难度 | 敌军 | AI |
| --- | --- | --- |
| 简单 | 数量持平、血/伤 0.85× | 各自扑向最近目标、不撤退，反应迟缓 |
| 困难 | 多 2 个团、血 1.2×/伤 1.15× | 集火弱侧、远程后置、受伤撤退、抢占防御地形、协同推进 |

敌方由 `Commander` 统一指挥：评估双方兵力后决定进攻或据守，安排远程兵种躲在近战
之后、把残血单位撤下火线、在不占优时抢占高防地形拖入僵持。

## 地图编辑器

开始界面点「地图编辑器」进入编辑模式，自己设计一张战场：

| 操作 | 说明 |
| --- | --- |
| 左键（地形工具） | 按笔刷大小涂地形，可按住拖动连续画 |
| 左键（兵团工具） | 在可通行处放一个当前阵营/兵种的兵团 |
| 左键（擦除工具） | 删除光标下的兵团（可拖动连擦） |
| **右键轻点** | 无论当前工具，都擦除光标下的兵团 |
| **右键拖拽** | 平移视角（与中键一致，编辑时更顺手） |
| 中键拖拽 / 方向键 / 滚轮 | 平移、缩放（与战斗一致） |

右侧面板选工具、地形（六种，带色块）、笔刷大小（1×1／3×3／5×5）、阵营（我军／敌军）
与兵种；还能**清空为平原**、**随机地形**、**清空兵团**、开关势力层，以及把整张剧本
**保存／载入**（JSON）。摆好后点「**▶ 试玩这张地图**」即在一份克隆世界上开打——
战斗里的伤亡不会改动你正在编辑的剧本，试玩结束按 Esc 原样回到编辑器继续调整
（双方至少各放 1 个兵团才能试玩）。

## 结构

```
main.py            入口
rts/terrain.py     地形定义、噪声地图生成、A* 寻路（不依赖 Qt）
rts/units.py       兵团数据、兵种外形、据守、画笔轨迹→可行军路线
rts/ai.py          难度设定与敌方指挥官 Commander
rts/influence.py   势力（影响力）场计算与领土统计
rts/editor.py      地图编辑器控制器：地形手绘、摆兵、存读档（不依赖 Qt）
rts/world.py       世界状态：移动、索敌、战斗、据守、AI、势力场、剧本存读档
rts/mapview.py     地图渲染（兵种形状、势力图层、小地图）与鼠标交互、编辑态
rts/ui.py          开始界面、战斗页、编辑器页、侧栏、页面切换外壳
smoke_gui.py       离屏冒烟测试（QT_QPA_PLATFORM=offscreen）
docs/              开发者代码文档（分模块 API / 公式 / 架构）
```

开发查阅请从 [`docs/INDEX.md`](docs/INDEX.md) 进入。

画笔路线：先按固定间距重采样并平滑手抖，再沿笔迹逐段推进——能直达的原样保留
（尊重笔触），被水面挡住的段落用 A* 绕过去再接回。笔触被当作「行进形状」平移到
每个兵团脚下，因此没有「先赶去起笔点」的绕行，多选也天然保持队形。
