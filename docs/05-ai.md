# 05 · 难度与指挥官（`rts/ai.py`）

## 1. `Difficulty`

| 枚举 | 值 | 名称 |
| --- | --- | --- |
| `EASY` | 0 | 简单 |
| `HARD` | 1 | 困难 |

## 2. `DiffParams`

| 字段 | 含义 |
| --- | --- |
| `key` | Difficulty |
| `name` / `desc` | UI 显示 |
| `hp_mult` | 敌军血量倍率 |
| `dmg_mult` | 敌军输出倍率 |
| `reaction` | 指挥官决策间隔（秒） |
| `extra_units` | 敌军额外兵团数 |

| `retreat` | 残血后撤 |
| `hold_terrain` | 不占优时抢高防格 |
| `coordinate` | True=协同逻辑，False=各自扑最近 |

## 2.1 托管参数 `AUTOPILOT_PARAMS`

我方托管指挥官用的一组 DiffParams：`reaction=0.8`，`retreat/hold_terrain/coordinate/focus_fire=True`，
倍率字段不生效（那些只作用于敌军补兵）。托管同样受战争迷雾约束。

## 3. 侦察 / 包抄 / 记忆常量

| 名 | 值 | 含义 |
| --- | --- | --- |
| `SPOT_MEMORY_TTL` | 8.0 s | 困难/托管：最后已知位置记忆时长 |
| `SPOT_MEMORY_TTL_EASY` | 4.0 s | 简单：更短记忆，弱化丢视野后死咬 |
| `RECON_ADVANCE` | TILE×10 | 侦察推进基准（历史值，现 `_recon_dir` 用固定远点） |
| `FLANK_OFFSET` | TILE×9 | 骑兵侧翼集结点相对敌军质心的横向偏移 |
| `FLANK_BEHIND` | TILE×3 | 侧翼切入时压向敌军纵深的距离 |
| `CAVALRY_FLANK_FAR` | TILE×4 | 骑兵距集结点超过此值先去集结，否则横切入 |
| `ARTY_GUARD_RANGE` | TILE×6 | 炮兵受威胁半径（敌近战进入则召护卫） |
| `ARTY_ESCORT_SLOTS` | 2 | 每门受威胁炮最多派几个近战护卫 |
| `FEINT_FRACTION` | 0.30 | 佯动分兵：近战中约三成压向侧翼次点 |

## 4. `Commander`

```python
Commander(faction, params, only_auto=False)
# World 中：commander=Commander(ENEMY, params)
#           autopilot=Commander(PLAYER, AUTOPILOT_PARAMS, only_auto=True)
```

| 成员 | 说明 |
| --- | --- |
| `cd` | 决策冷却，初值 0.3 |
| `only_auto` | True 时只指挥 `u.auto` 的兵团（我方托管） |
| `_known` | `dict[uid → (x,y)]` 最后已知敌军位置 |
| `_known_t` | `dict[uid → 时刻]` 记忆时间戳 |
| `_birth_side` | +1=左侧出生（敌方在右）/ -1=右侧出生（敌方在左），首次决策按己方质心相对中线推断 |

### `update(world, dt)`

```
cd -= dt
if cd > 0: return
cd = params.reaction
army = 全军；mine = only_auto ? [u for u in army if u.auto] : army；剔除 routing
foes = 对方全军
mine / foes 为空则 return
首次决策：按 mine 质心相对地图中线推断 _birth_side
vis_foes = [e for e in foes if world.visible_to(self.faction, e)]
_refresh_memory(world, foes, vis_foes)
coordinate? _coordinated(mine, foes, vis_foes, army) : _simple_push(mine, vis_foes)
```

**战争迷雾约束**：进攻 / 集火 / 包抄瞄准只对 `vis_foes` 下令；不可见者靠
`_known` 的最后已知位置维持推进，过期遗忘。`_coordinated` 的实力评估仍看
`army` 全军与 `foes` 全军（宏观对比），但战术目标（focus / 侧翼 / 炮兵 aim）
只取 `vis_foes`——既不透视全图，也不会因一时丢失视野就原地发呆。

### 记忆维护 `_refresh_memory(world, foes, vis_foes)`

- 可见敌军刷新 `(x, y)` 与时刻；
- 阵亡（不在 foes）或超过 `SPOT_MEMORY_TTL` 的 uid 遗忘。

### `_nearest_known(u)` / `_recon_dir(world, my_com)`

- `_nearest_known`：离 u 最近的最后已知敌军位置，无记忆返回 None。
- `_recon_dir`：无可见时的侦察推进点 = 朝推断的敌方出生侧远点（地图对侧
  85%/15% 处）。用**固定远点**而非「质心 + 偏移」，避免单位到达后质心停滞、
  目标随之停滞的死锁；途中一旦发现敌军，上层即切换为可见目标进攻。

## 5. 简单模式 `_simple_push(mine, vis_foes)`

对每个己方单位：

- 已在交火（`_engaged`）→ 跳过；
- 已有 path → 跳过；
- `vis_foes` 非空 → 扑向**最近可见**敌军；
- 否则 → 短时记忆追击（TTL=`SPOT_MEMORY_TTL_EASY`）；记忆点过远（>TILE×14）改侦察，不远征死咬。

## 6. 困难模式 `_coordinated(mine, foes, vis_foes, army)`

### 全局评估

```
my_str  = sum(army.hp)              # 评估看全军（含手操兵团）
foe_str = sum(foes.hp)
my_com  = mine 质心
foe_com = vis_foes 质心 ? 记忆质心 : foes 质心   # 三级退化，仅作方向估算
focus   = _pick_focus：优先镜像玩家 order=attack 的可见目标，否则弱且近
rally   = my_com*0.45 + (focus 或 foe_com)*0.55
attacking = my_str >= foe_str * 0.85             # 否则据守拖僵持
van     = 近战质心（无近战则 my_com）
flank   = (attacking and vis_foes) ? _flank_rally(...) : None
escorts = 受威胁炮 → 近战护卫名单
feint   = 近战约 30% 压向侧翼次点（佯动分兵）
```

### 每单位优先级

1. **撤退**（`retreat` 且 `hp_ratio < 0.30` 且被威胁）
   → 退到质心相对 anchor_pt 的后方 `TILE*6`，`force=True`。

2. **已交火** → 不动（交给战斗）。

2b. **护炮**（uid 在 escorts）→ 赶往炮附近护卫点。

3. **骑兵侧翼包抄**（cavalry 且 attacking 且 flank 非空）
   - 距 flank > `CAVALRY_FLANK_FAR` → 去侧翼集结点；
   - 否则 → 横切入 `foe_com`（从侧面冲入触发侧击 / 背击）。

4. **远程**
   - 炮兵受近威胁：略后撤 `_behind`；
   - 炮兵 + `vis_foes`：`aim = max(vis_foes, key=artillery_target_value)`（高价值优先）；
   - 弓兵 / 弩兵：`aim = focus`（进攻时）/ None；
   - aim 为 None：随全军侦察推进（`_nearest_known` / `_recon_dir`），避免远程拖死整体；
   - 有 aim：站位 `van*0.7 + aim*0.3`，偏离 > `TILE*2.5` 才重下令。

5. **近战 · 进攻**（feint 组成员压向侧翼次点，其余主攻 focus）
   - focus 非空：距 rally > `TILE*8` 先集结，否则压 focus；距 focus > `TILE*3` 才下令；
   - focus 为 None：向最近记忆 / 侦察方向推进，保持接触。

6. **近战 · 据守**
   - `hold_terrain` 时 `_defensive_spot` 找附近更高防格；
   - 明显更好且距离 > `TILE*1.5` 则移动。

## 7. 包抄几何 `_flank_rally(foe_com, my_com, cav_com)`

- 主攻方向单位向量 `u = (foe_com - my_com)` 归一化；
- 两侧法向量 `perp = (-uy, ux)` / `(uy, -ux)`；
- 两侧候选点 = `foe_com + perp*FLANK_OFFSET - u*FLANK_BEHIND`（敌阵侧后方）；
- 选离 `cav_com` 更近的一侧，少绕路。

## 8. 工具方法

| 方法 | 作用 |
| --- | --- |
| `_engaged` | 目标存在且距离 ≤ range×1.05 |
| `_threatened(u, foes)` | 任敌距离 ≤ 其 range×1.3（参数为可见敌军） |
| `_far(u, pt, tol)` | 距 pt > tol |
| `_behind(com, target_pt, dist)` | 从 target_pt 指向 com 再延伸 dist（接受点参数） |
| `_march(world, u, pt, force=False)` | `set_path([pt])`，设 `ai_cd = reaction×(0.8 if path else 0.4)` |
| `_defensive_spot` | 5 格半径内 `score=defense-0.03*(|dx|+|dy|)`，需高于当前防 +0.05 |

### `_march` 的 ai_cd

```
ai_cd = reaction * (0.8 if path 非空 else 0.4)
```

非 `force` 时 `ai_cd>0` 不重新下令，防每拍抖路径。

## 9. 与 World 的分工

| 能力 | 位置 |
| --- | --- |
| 集火索敌（含炮兵高价值评分） | World.`_acquire_targets` + `params.focus_fire` |
| 可见性判定 / 移动意图 | Commander（受迷雾约束，记忆辅助） |
| 伤害 / 据守 / 分离 | World |
| 玩家指令 | World.`issue_*`（AI 不碰玩家 path，除非未来扩展） |

炮兵目标价值函数见 [03-units](03-units.md) `artillery_target_value`。
