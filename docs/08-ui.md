# 08 · UI 层（`rts/ui.py`）

## 1. 常量

| 名 | 值 | 含义 |
| --- | --- | --- |
| `TICK_MS` | 33 | 主循环间隔 ms（≈30 FPS） |

## 2. 组件树

```
GameShell (QMainWindow)
└─ QStackedWidget
   ├─ StartScreen
   ├─ BattlePage
   │  ├─ MapView
   │  ├─ 工具栏按钮行
   │  ├─ SidePanel
   │  │  ├─ summary
   │  │  ├─ StrengthBar + note
   │  │  ├─ unit_list（选中）
   │  │  ├─ legend（兵种+地形）
   │  │  └─ log_list（战报）
   │  └─ status 底栏
   └─ EditorPage
      ├─ MapView（edit_mode=True）
      ├─ 控制面板（工具/地形/笔刷/兵团/地图/剧本/试玩）
      └─ status 底栏
```

## 3. `StrengthBar`（军力对比条）

- 高 30px；
- `set_values(p, e)`：`p/e` 为双方**有效战力**（`army_strength`：Σ 当前HP × 老练输出加成 × 难度系数，溃兵折三成）；
- 显示占比向目标**缓动**（每帧 18%，≈0.4s 收敛），天平慢慢倾斜；
- 绘制：底槽 + 蓝/红横向渐变色带（向交锋线渐亮）+ 玻璃高光 + 50% 均势虚线刻度 + 金色交锋线（带辉光）+ 左右文字「我军 xx%」「xx% 敌军」。

## 4. `SidePanel`

| 区 | 数据源 |
| --- | --- |
| summary | elapsed、难度名、双方存活团数、种子 |
| 军力对比 | `army_strength(units_of(...))`，附强弱判词（压倒/上风/均势） |
| **战况记录** | 按钮 → 暂停 + `BattleReportDialog`（军力折线 + 时间线） |
| 战况统计 | `world.stats`：双方击破/损失/输出 |
| 选中列表 | `world.selected`：名、uid、HP、地形、行军/据守/攻移/巡逻/编队/托管/破N团 |
| 图例 | 四兵种符号 + 六种地形色块与速防攻 |
| 战报 | `events` 末 60 条，变化时刷新 |

`set_world`：换战场时重置 log 游标。

## 5. `BattlePage`

### 构造

- `World(seed, difficulty)`（或直接传入 `world=` 试玩克隆）+ `MapView` + `SidePanel`；
- `back_label` 决定「返回…」按钮与结束对话框文案（默认「主菜单」，试玩为「编辑器」）；
- 启动 `QTimer` → `_tick`；
- 信号：`exit_to_menu`。

### 状态

| 成员 | 说明 |
| --- | --- |
| `paused` | 暂停 |
| `speed` | 1 / 2 / 4 |
| `_ended` | 已出胜负，停止模拟 |

### 工具栏

暂停、速度、全选、停止、**撤退 (R)**、**指令模式按钮组（移动/攻击移动/巡逻）**、**编队开关**、托管、势力图、网格、新战场、主菜单 + 操作提示。

「指令模式」`_set_order_mode(mode)`：切换 `view.order_mode`，决定**点地/拖拽**的指令类型；底栏写明「点敌＝锁定　点地/拖拽＝当前模式」。
「编队 (Q)」`_toggle_formation`：开关 `view.formation_lock`，下令时选中兵团以最慢者速度同步推进、保持队形。
「托管 (J)」`toggle_auto`：选中兵团交给我方 autopilot 指挥；若选中的已全部托管则解除。无选中时仅在底栏提示。
「控制编组」：`Ctrl+1..9` 存选中，`1..9` 召回（连按居中）。

### 快捷键（WidgetWithChildren）

| 键 | 动作 |
| --- | --- |
| Space | 暂停 |
| Ctrl+A | 全选我军 |
| H | 停止选中 |
| R | 战术撤退（向出生侧短撤） |
| J | 托管/解除选中 |
| M / A / P | 切换指令模式：移动 / 攻击移动 / 巡逻 |
| Q | 编队锁定开关 |
| Ctrl+1..9 | 存当前选中为控制编组 |
| 1..9 | 召回编组（约 0.35s 内连按同一键＝居中） |
| F | 战争迷雾开关 |
| T / G | 势力 / 网格 |
| F5 | 新战场（同难度，新随机种子） |
| Tab | 视角居中选中 |
| Esc | 回主菜单（停 timer + emit） |

`control_groups: dict[int, list[int]]` 存 uid；新战场清空。召回时过滤阵亡/溃逃。

### `_tick`

每帧先 `view.tick_fx(base)`（攻击下令红圈等 UI 特效，暂停也走墙钟），再按倍速 `world.update`。
见 [01-architecture](01-architecture.md)。胜负 → `_show_result`：
标题 + `world.battle_summary(winner)`（RichText 结算：时长/齐射/首次交火/双方战损/全场最佳），再战 / 回菜单。

### `new_battle`

新 `World(difficulty=self.difficulty)`（种子随机），刷新 view/panel，清 `_ended`。

## 6. `StartScreen`

- 难度按钮组 → `_pick` 更新 desc；
- 种子输入：空=None；整数；否则 `zlib.crc32(text)%(1<<30)`（`_parse_seed` 统一处理，跨进程可复现）；
- 「开始战斗」/ 回车 → `start_requested.emit(difficulty, seed)`；
- 「地图编辑器」→ `editor_requested.emit(difficulty, seed)`（复用同一难度/种子）。

## 6.1 `EditorPage`

地图 / 剧本编辑器页，详见 [11-editor](11-editor.md)。要点：

- 左 `MapView(edit_mode=True)` + 右控制面板（工具/地形/笔刷/兵团/地图/剧本）+ 底栏；
- 信号 `exit_to_menu`、`playtest_requested(World)`；
- 「试玩」发出 `world.clone()`，战斗在克隆上进行，不动编辑器剧本。

## 7. `GameShell`

| 方法 | 行为 |
| --- | --- |
| `_start_game` | 销毁旧 battle/editor，建 BattlePage 并 focus 地图 |
| `_to_menu` | 显示 start，销毁 battle |
| `_open_editor` | 建空世界（`populate=False`）+ EditorPage |
| `_editor_to_menu` | 显示 start，销毁 editor |
| `_start_playtest(world)` | 编辑器留栈，克隆世界建 BattlePage（back_label=编辑器） |
| `_playtest_to_editor` | 销毁试玩 battle，回到编辑器 |

窗口默认 1380×880，标题「笔锋 · 实时战略」。

## 8. 样式 `DARK_QSS`

深色「夜战沙盘」主题：背景 `#10131a`，按钮金属渐变压边、checked 态染军蓝；侧栏 `#sidepanel` 带左描边；分区标题 `#sectionhdr` 金色竖条；开始卡片 `#card` 暗琥珀描边。  
字体：Microsoft YaHei / Segoe UI。

## 9. `run() -> int`

```python
app = QApplication.instance() or QApplication([])
app.setStyleSheet(DARK_QSS)
shell = GameShell(); shell.show()
return app.exec()
```

`main.py`：`sys.exit(run())`。
