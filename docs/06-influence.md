# 06 · 势力场（`rts/influence.py`）

## 1. 设计目标

- 每个兵团向周围投射**衰减影响力**；
- 每格比较双方强度，**硬划分**归属（+1 我 / -1 敌）；
- **无中立带**（双方都无单位时用 default：全歼一方则整图归另一方）；
- 用于：势力图层渲染、侧栏控制面积比。

## 2. 常量

| 名 | 值 | 含义 |
| --- | --- | --- |
| `INF_STEP` | `3` | 影响力格 = 3×3 地形格 |
| `INF_RADIUS` | `150.0` 像素 | 影响力半径（硬截断，超出无贡献） |

默认地图 160×120 → 影响力网格约 **54×40**。

## 3. `InfluenceField`

| 字段 | 说明 |
| --- | --- |
| `gw, gh` | 网格宽高 |
| `step_px` | `INF_STEP * TILE`（默认 48） |
| `owner[gy][gx]` | +1 / -1 / 0（0 仅可能 default=0 且双方都无） |
| `player_cells` | 我方控制的**可通行**格数 |
| `enemy_cells` | 敌方同理 |

### 方法

| 方法 | 说明 |
| --- | --- |
| `total_controlled` | player + enemy |
| `share()` | `(p_ratio, e_ratio)`，和为 1；全 0 时 (0.5, 0.5) |
| `owner_at(gx, gy)` | 越界返回 0 |

## 4. `compute_field(world)`

### 4.1 存在感

```python
_presence(u) = 0.5 + u.hp_ratio   # 残血压制度下降
```

### 4.2 影响力散布（scatter，`_splat`）

影响力在 `INF_RADIUS` 处**硬截断**——每个兵团只写自己半径覆盖到的格子：

```
w = 1 - (dx²+dy²) / R²      # 半径外 w<=0，无贡献
grid[gy][gx] += presence * w
```

复杂度 = 单位数 × 各自覆盖格数（默认约 7×7 格），与网格总数无关，
远快于旧版「每格遍历每个单位」的 gather，且**远方大军无法隔空施压**：
旧版 `1/(1+d²/R²)` 长尾不为零，12 个远处敌团的尾巴加起来能压过孤军
脚下的贡献，造成「兵团还在、势力为 0」。截断后活兵团脚下必归己方。

### 4.3 归属划分 + 泛洪

1. `pv/ev` 任一非零的格：`o = 1 if pv >= ev else -1`（平局归我），并入 BFS 队列；
2. 双方都够不到的格：从已归属格 4 邻 BFS 泛洪，就近染色，不留无主带；
3. 一方全歼：整图直接归另一方；双方皆无：全 0。

### 4.4 面积统计

取格内代表地形点（`gx*INF_STEP + INF_STEP//2`），`passable` 才计入 pc/ec（水面不计入领土对比）。
通行性表由 `_passable_cells` 按 `(map_uid, terrain_version, gw, gh)` 缓存在
`gm._inf_pass_cache`——地形不变时零地形查询，编辑器改地形或整体换图才重建。

## 5. 刷新时机

`World.update` 中 `_field_cd`，间隔 `INFLUENCE_INTERVAL=0.4s`；开局立即算一次。
`refresh_field` 带**脏检查**：战场签名（地形版本 + 各兵团量化位置/血量）与上次
相同则跳过整套 splat/BFS/统计，也不 bump `field_version`——布阵、暂停、僵持
静坐等没人动的时段完全免费。

## 6. 渲染消费（MapView）

- 半透明平铺 `owner` 色块（α=60）；
- 与相邻格 `owner` 符号相反时画前线（右邻/下邻）；
- 视口裁剪只画可见格。

## 7. UI 消费

侧栏军力对比条（`StrengthBar`）已改为按**兵力**统计（见 [08-ui](08-ui.md)），不再消费 `field.share()`；势力场现仅用于主图/小地图的占领区图层渲染。
